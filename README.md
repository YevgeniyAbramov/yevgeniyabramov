## Ключевой опыт

- **Микросервисы:** Разработка и поддержка микросервисной платформы автоматизации документооборота для госуслуг.
- **Архитектура:** Проектирование мульти-аккаунтной модели (разделение “Пользователь” / “Аккаунт”) для масштабируемости и гибкости системы.
- **Безопасность:** Аудит **300+ SQL-запросов**, устранение рисков SQL-инъекций, усиление защиты API.
- **Интеграции:** Переход внешних интеграций с SOAP на JSON API, упрощение поддержки и расширения бизнес-логики.
- **Performance / Observability:** Перенос логов из реляционной БД в Elasticsearch — снижение нагрузки и ускорение поиска/аналитики.
- **Production:** Поддержка сервисов в Kubernetes: диагностика по логам, анализ инцидентов, сопровождение в проде.
